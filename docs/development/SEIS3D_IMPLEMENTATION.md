# Seis3D 实现与使用说明

## 当前实现范围

在当前 `CMakePro_CUDA_SeisSim_V2` 项目内加入独立三维子系统，保留原有程序名称和二维求解器。三维 C++/CUDA 类型、函数、状态和算法全部位于 `namespace Seis3D`，以独立静态库目标 `Seis3D` 编译。

```text
CMakePro_CUDA_SeisSim_V2/
├─ include/Common3D.h          物理上下文、GPU 指针、内存预算和视图布局
├─ include/Seis3D_Sim.h        独立 UI 状态、GL 句柄、观测系统和道集快照
├─ cuda/Cuda_Seis3D.cuh        CUDA 求解器接口
├─ cuda/Cuda_Seis3D.cu         差分、CPML、自由表面、切片和接收点核函数
├─ src/Seis3D_Sim.cpp          会话生命周期、计算推进与资源释放
├─ src/Seis3D/
│  ├─ Workspace3D.cpp         DockSpace、参数面板、切片交互与图例
│  ├─ SliceView3D.cpp         剖面缩放、平移、网格叠加与坐标拾取
│  ├─ Renderer3D.cpp          CUDA/GL 互操作、纹理和渲染缓存
│  ├─ ModelIo3D.cpp           三维模型检查、流式导入导出
│  ├─ Acquisition3D.cpp       接收系统、道集和 SEG-Y 导出
│  ├─ TraceView3D.cpp         有界实时波形监视、正式道集预览和曲线绘制
│  ├─ Internal3D.h           模块内部接口与异常处理
│  └─ Visual3D.h             共享显示调色板和图例映射
└─ shaders/
   ├─ seis3d_slice.vert
   ├─ seis3d_slice.frag
   ├─ seis3d_volume.frag
   └─ seis3d_transfer.glsl    切片与体绘制共用的颜色映射
```

三维不使用二维的 `ctx`、`gpu_data`、`rec`、`g_replay`、纹理、程序或模拟运行状态。窗口、ImGui/ImPlot 主上下文、界面主题和可执行文件路径查询属于应用层服务。三维内部不创建或销毁主窗口/ImGui 上下文。

首页现在由独立的 `Main_cpp/HomeScreen.cpp` 实现，应用层 `AppUi` 库管理主题和导流界面；不再保留三维模块内重复的首页卡片绘制代码。首页包含实际设备信息、双模式入口、流程提示与示意波前动画；窄窗口将双卡片改为纵向布局。下方增加四张流程说明卡、三维网格起步建议和剖面操作指引，入口卡片随可用高度伸展，页脚靠近窗口底部；小窗口允许滚动查看完整内容。

### 界面主题

首页右上角提供八套主题：**CUDA Green / Ocean Blue / Graphite / Scientific Light / Midnight Violet / Teal Studio / Amber Lab / Paper Sand**。其中 Scientific Light 与 Paper Sand 为浅色主题。三维也可通过 `Workspace > Interface theme` 或 `Display / materials` 切换。主题改变界面背景、文字、控件和停靠标签的颜色，波场和材料配色仍由显示设置独立控制。新增主题追加到原有索引之后，兼容已保存的四种主题偏好。

主题记录在程序旁 `out/bin/<配置>/ui_theme.ini`，重新启动时加载。无法保存时仍即时应用当前主题，并在选择器悬停提示原因。旧页面在浅色主题下使用局部深色对比适配，保证已有深色波场画布和半透明面板上的文字可读。

## 进入与交互

1. 首页选择 **3D Spatial Exploration Sandbox / 三维空间探索沙盒**。
2. 在 `Simulation3D` 选择网格和材料，点击 **Initialize 3D**。
3. 点击 **Run**，或在 `Source3D` 点击 **Reset wavefield + fire**。
4. 三个切片分别为 X-Z（固定 Y）、Y-Z（固定 X）、X-Y（固定 Z）。滑块或点击切片可以联动交叉线，悬停位置显示物性。鼠标在剖面内滚轮缩放（100%–3200%，以鼠标位置为中心）、中键拖动平移、左键点击联动位置。各剖面分别保存视图；`Reset view` 恢复当前剖面全景，顶部 `Reset views` 恢复三剖面与轨道相机。重置视图保持切片位置与波场不变。
5. 辅助体视图支持左键旋转、右键拖动或滚轮缩放、中键平移。`Display / materials` 可关闭体绘制、切换分量和调整尺度。
6. `Space` 运行/暂停，`C` 重置波场，`R` 重置三剖面与轨道相机，`Tab` 或 **Home / cold switch** 返回首页。体视图也提供独立的 `Reset camera` 按钮。

初始化时同时布设有效的接收系统，默认 100 点。普通 **Run** 会在底部生成实时波形；达到停止步数后按钮变为 **Replay**，点击会从新震源重新计算。**Reset fields** 重置波场并暂停，顶部 **Fire + capture** 则开始正式单炮采集。

剖面缩放使用现有完整分辨率纹理的 UV 窗口，不申请额外三维显存。物理网格、交叉线、震源/接收点和物性坐标拾取共用视图变换；放大后仍按原始格点拾取。缩放和平移被约束在模型范围内；到达边缘时中心会被限制。重新初始化或导入模型会恢复全部相机。

三维按需分配资源，首次进入不自动申请大体积显存。离开模拟页面后，在下一帧绘制前释放该模式的 GPU/GL 资源，避免销毁仍被上一帧 ImGui 指令引用的纹理。目标模式分配之前完成释放。

### 可停靠工作区与显示样式

顶部 `Workspace` 提供 Four views（四视图）、Volume focus（体视图优先）、Compact / tabbed（紧凑标签页）预设，以及恢复布局、重新打开已关闭窗口的菜单。参数、显示设置、三正交切片、体视图和接收道曲线均为真正的 ImGui 停靠窗口，可拖动标签、拆分、合并和调整大小。三维窗口使用专属 WindowClass，避免与其他模式的窗口混合停靠。

布局由 ImGui 保存到程序旁 `out/bin/<配置>/imgui.ini`；切换预设会重建布局并重新打开窗口。当前不持久化每个窗口的关闭状态和显示参数。参数控件名称位于输入框上方，初始化按钮位于面板顶部，窄窗口可以滚动查看剩余参数。

在 `Display / materials` 中选择：

- **Model + wavefield**：地质模型作为背景，波场按幅值透明叠加，零波场仍能看见材料分层。
- **Wavefield only**：只显示波场。
- **Material only**：只显示 Vp、Vs 或密度。

波场提供二维页面同名的 13 种配色，加上 CUDA Green；包括 Seismic Bipolar、Coolwarm、PuOr、Viridis、Turbo 等。三维采用五个颜色节点插值的近似调色板，并非 Matplotlib 完整查找表或二维着色器的逐像素复制。图例与三维着色器使用同一组颜色节点。幅值、增益、透明度和阈值独立可调；图例显示的是透明混合前的颜色与物理量范围。

提供五套显示预设：**Wavefront contrast / Signed seismic / Geological layers / CUDA glow / Paper scientific**，可在显示面板或 Workspace 菜单中切换。初始选择速度幅值、Turbo 和较暗的材料背景，避免单个速度分量在对称剖面上为零时误以为波场未计算。Paper scientific 配合 Paper Sand 使用 Scientific White 浅色分层、Coolwarm 蓝红波场、浅色体视图以及适配的网格、十字线和标记；增益为 1.8，波场透明度为 1.0，gamma 为 0.50。`Restore readable display` 在浅色界面下恢复 Paper scientific，在其他主题下恢复 Wavefront contrast。`Weak-wave visibility` 仅改变波场透明度的 gamma 映射，`Material background` 调整叠加模式背景亮度；这些选项不修改物理振幅、采集样本或导出数据。纯材料模式仍使用原始材料颜色。

各剖面带有物理坐标标尺和当前分量/单位标签；放大和平移时标尺随 UV 区间更新。四视图的新默认布局为底部曲线分配更多高度；已有用户布局继续保留，可以通过 Workspace 重新应用布局预设。

模型提供 Dark Titanium、Geological Map、Grayscale Velocity、WaveStyle Synced、Scientific White 五种样式，独立选择 Vp / Vs / Density。自动材质范围来自当前抽取的切片和辅助显示体；为比较不同位置或模型，可冻结范围或手动设置。均匀模型使用色带中值，避免零范围除法。模型材质与波场共用 RG32F 显示存储的两个独立通道，不复制完整物理体。

显示每 N 个计算步更新一次可以减少抽取和上传开销；修改切片或物性选择会立即使显示缓存失效。暂停且相机、样式、数据均无变化时跳过重复的离屏绘制。显示数值范围统计按 warp 归约后再执行原子更新，减少线程竞争。这些调整不改变 dt、求解方程或接收点采样间隔，也没有测得可用于承诺的性能提升百分比。

退出三维时可以保留最后一次采集的 CPU 道集以供导出；波场、CPML、接收点 GPU 缓冲、CUDA 流、GL 纹理、着色器和互操作注册均释放。重新进入后需要初始化波场。二维退出时也停止采集/回放并释放二维模拟资源。

## 数值计算

- 三维各向同性一阶速度—应力方程，3 个速度分量和 6 个对称应力分量。
- X 为显存连续维度。物理网格外增加 CPML 与 4 层差分 ghost cells，界面尺寸和导出模型均不包含这些填充层。
- 固定八阶交错一阶空间差分，权重 `1225/1024, -245/3072, 49/5120, -5/7168`。每个方向使用 8 个采样点，三方向形成 24 点十字邻域。
- 二阶 leapfrog 时间推进；速度位于半时间步，应力位于整数时间步。
- 速度点使用面中心平均密度；剪切点使用四单元调和平均剪切模量，零剪切模量不会被自动改成固体。
- 震源采用归一化 3×3×3 空间分布和 Ricker 时间函数。爆炸源幅值为应力率 Pa/s，体力源为 N/m³；不是未经标定即可解释为地震矩的震源参数。
- 爆炸源注入法向应力；体力源按三方向向量注入速度更新。

### CPML

使用非分裂卷积记忆变量：`psi = b * psi + a * derivative`，`filtered = derivative/kappa + psi`。

每个方向有 6 个独立导数记忆槽，仅在该方向的 CPML 薄层分配，角点同时拥有各自方向的记忆。普通物理区不保存 PML 记忆。中心和半格点分别生成系数；自由表面开启后，不分配顶部 Z 向 CPML。

当前固定参数：三次阻尼轮廓、目标反射参数 `1e-6`、`kappaMax=3`、`alphaMax=pi*f0`。这里的 `1e-6` 是系数设计参数，**不代表实测反射系数**。算法依据见 [Komatitsch 与 Martin 的 CPML 资料](https://specfem.org/komatitsch.free.fr/README_seismic_cpml.html)；实现使用独立编写的 CUDA 代码。

### 平面自由表面

物理顶面为 Z=0，对应填充网格 k=4。`sigma_zz` 在整数面置零并做奇对称镜像；`sigma_xz`、`sigma_yz` 按各自的半格位置做奇对称镜像，牵引力在物理表面插值为零。

速度 ghost 映射满足：

```text
d(vx)/dz = -d(vz)/dx
d(vy)/dz = -d(vz)/dy
d(vz)/dz = -lambda/(lambda+2*mu) * (d(vx)/dx+d(vy)/dy)
```

表面 Vz 使用首两个半格点做二阶外推；表面法向应力更新同步施加同一约束。**内部空间八阶，平面表面闭合二阶**。当前不支持起伏地形、曲面自由表面或全局八阶表面闭合。

### 安全时步与输入防御

`S=sum(abs(staggeredWeights))`，采用：

```text
safeDt = cflSafety * spacing / (sqrt(3) * maxVp * S)
dt = floor(safeDt * 1e6) / 1e6
```

默认安全系数 0.85，最大允许 0.9。时步向下量化到整数微秒。量化后不足 1 微秒，或超过实现时步范围 65535 微秒时明确拒绝初始化。采集时另行检查 SEG-Y rev1 的正有符号二字节范围，实际抽取间隔不得超过 32767 微秒。

导入模型先逐单元检查 Vp/Vs/rho，并扫描最大 Vp；拒绝非有限数、非正密度和非正体积模量。GPU 更新检测非有限波场并暂停三维工作区，不继续导出损坏样本。

## 显存预算

以下为物理节点数，CPML=12，平面自由表面开启，包含填充网格、九个物理场、三个材料场、CPML、显示纹理和 staging 的**代码预算估算**：

| 网格 | 场与材料 | CPML | 总预算 |
|---|---:|---:|---:|
| 96³ | 0.085 GiB | 0.020 GiB | 0.121 GiB |
| 160³ | 0.297 GiB | 0.047 GiB | 0.378 GiB |
| 300³ | 1.577 GiB | 0.144 GiB | 1.759 GiB |
| 400×400×300 | 2.670 GiB | 0.198 GiB | 2.909 GiB |

预算硬上限 4 GiB。分配前查询实际剩余显存，并额外保留 `max(512 MiB, 设备总显存的20%)`。驱动、显示系统和 CUDA 模块另有占用，实际剩余量以顶部状态栏为准。

三正交切片使用完整网格抽取；体绘制仅使用每轴最多 128 点的显示体，避免重复保存完整三维纹理。显示体为探索性采样，可能遗漏薄层和细小高频波前，不用于振幅测量。CUDA/GL 互操作使用独立注册的 PBO，映射和解除映射使用三维自己的 CUDA 流；参考 [NVIDIA 互操作文档](https://docs.nvidia.com/cuda/cuda-programming-guide/04-special-topics/graphics-interop.html)。

默认限制每帧 1–8 个时间步，防止 GPU 工作无限排队。300³/400×400×300 的实际 FPS 依赖 GPU、构建配置、切片/体绘制开销，当前没有实测帧率承诺。

## 三维采集与 SEG-Y

### 实时波形与正式采集

底部预览可选择 **Auto / Live / Captured**。普通运行按每个计算批次抽取 Vx/Vy/Vz，保存实际半时间步时间戳，最多保留最近 512 帧、100 点、三分量，CPU 缓冲约 600 KiB。该监视序列可用于观察信号到达，不作为等间隔正式道集导出。

正式采集仍按指定 stride 记录每道样本，冻结采集几何，保存独立 CPU 快照。开始正式采集会清空实时预览；后续普通 Run、Replay 和实时环形缓冲不会覆盖已有正式道集。Auto 在正式采集或暂停且有道集时显示 Captured，否则显示 Live。接收点滑块可切换预览位置；未到波时给出提示。绘图最多显示 2048 个抽取点，不减少保存或导出的样本。

`Data Acquisition 3D` 支持：

- 按 XYZ 原点、XY 节点数和间距布设接收网格，**默认 10×10＝100 个接收点，总上限 100**；Z=0 表示地表。之前的默认 8×8 是 64 个接收点，原实现的上限为 4096。
- 道数按 `receiverCountX × receiverCountY` 计算，界面提供 64 / 100 道预设。界面调整数量时约束总数；采集配置与 CUDA 接收点 API 也拒绝超过 100 道，失败时保留此前有效的接收系统。数量限制以外，布设范围仍必须落在模型中。
- 每个接收点同时记录 Vx/Vy/Vz；每个分量的 SEG-Y 文件最多包含 100 道，三个分量导出为三个文件。
- 按首炮 XYZ、每线炮数、源线数和 XY 间距布设矩形多测线震源，逐炮重置和采集。
- 单炮最多 32767 样本，实际采样间隔最多 32767 微秒，三分量 CPU 缓冲上限 512 MiB。采集期间冻结模型、震源、观测系统和时步。
- 接收值为面中心速度在单元中心的空间插值。步长 stride 采样，首样本时间为 `(stride-0.5)*dt`，后续间隔为 `stride*dt`。
- 每炮输出 `_vx.sgy`、`_vy.sgy`、`_vz.sgy` 和 `_geometry.csv`，多炮输出到独立会话目录；失败时保留 CPU 道集供重试。
- 主体采集和文件 I/O 当前在 UI 线程驱动；大文件导入/导出期间界面可能短暂停顿。尚未实现后台文件队列或无限时长采集。

依据 [SEG-Y rev1 官方标准](https://seg.org/wp-content/uploads/2025/11/seg_y_rev1.pdf)，采用 ASCII 文本头、400 字节二进制头、240 字节道头及大端 IEEE float32 样本。明确标记共炮点排序。

| 道头字节（从1计数） | 内容 |
|---|---|
| 9–12 / 13–16 | 炮号 / 炮内道号 |
| 29–30 | 三分量标识：Vx=Inline(14)，Vy=Crossline(13)，Vz=Vertical(12) |
| 69–70 | 高程比例因子 -1000 |
| 71–72 | 坐标比例因子，自动选用 -1000/-100/-10/1 防止大坐标溢出 |
| 73–76 / 77–80 | 源点 Sx / Sy |
| 81–84 / 85–88 | 接收点 Gx / Gy |
| 89–90 | 坐标单位：长度，文件测量单位为米 |
| 109–110 / 215–216 | 首样本延迟 / 时间比例因子 |
| 115–116 / 117–118 | 样本数 / 采样间隔，微秒 |
| 181–184 / 185–188 | 源检中点 XY |
| 189–192 / 193–196 | CMP Inline（Y方向分箱）/ Crossline（X方向分箱） |
| 203–204 | 道值单位：m/s |

CMP 分箱以模型物理 XY 原点为起点，使用源检中点和指定的 XY 箱宽，一起加上世界坐标原点偏移。当前是局部直角坐标加原点偏移，**不执行投影坐标转换、旋转测网变换、CMP 叠加或偏移成像**。

SEG-Y 的首样本延迟字段采用允许范围内尽可能精细的十进制时间比例。若量化不能精确表达半时间步，文本头和 CSV 仍保留精确起点；需要精确对时的软件应读取 CSV。部分老软件忽略道头时间比例，导入时需要自行设置首样本时间。

## .s3dm 模型格式

采用 Windows x64 小端 IEEE float32 物性体，36 字节头：

```text
0..7    magic = "S3DMOD1\0"
8..11   uint32 version = 1
12..15  uint32 nx
16..19  uint32 ny
20..23  uint32 nz
24..27  uint32 CPML thickness
28..31  uint32 freeSurface (0 or 1)
32..35  float32 spacing in metres
36..    float32 triples [Vp, Vs, rho], X fastest, then Y, then Z
```

只有物理单元写入模型文件，CPML/ghost 材料由边缘外推生成。频率、震源与观测系统不保存在此模型格式中。导出模型需要指定新文件名；使用临时文件完成写入后才改为正式文件名。

## 构建与资源部署

延续项目约定：所有产物位于外层 `out`。三维库输出到 `out/lib/<配置>/Seis3D.lib`；程序旁新增 `resource_Seis3D`，修改着色器后自动部署。二维资源仍位于 `resource_CUDA_V1`。

VS 从外层或内层入口构建均包含三维库。三维目标单独编译，不继承二维 `--use_fast_math`。应用和三维目标统一使用共享 CUDA Runtime，避免静态/动态 cudart 同时链接。

2026-10-12 已完成以下主程序目标的编译与链接（MSVC 19.44、CUDA 12.8）：

| 构建入口 | 配置 | 最终程序目录 |
| --- | --- | --- |
| 外层 CMake | Debug | `out/bin/Debug` |
| 内层 CMake / VS 独立入口 | Debug | `out/bin/Debug` |
| 外层 CMake | RelWithDebInfo | `out/bin/RelWithDebInfo` |

两种输出配置均部署三维切片与体绘制着色器；内层源码目录没有新增 `out`。MSVC/Ninja 对中文包含前缀的编码处理已修复，避免头文件变化后继续使用旧渲染目标文件，细节见 [构建说明](../build/BUILDING.md)。

Paper 风格图文说明见 [三维使用指南](../user/Seis3D_User_Guide.md)。`--capture-seis3d-paper` 在真实程序中生成首页、四视图与显示设置截图，临时使用 Paper Sand 和 Paper scientific，不保存主题偏好或布局。浅色主题下的接收曲线使用蓝、铜、紫色提高对比度。

## 验证边界

首版仅进行编译和代码审阅。本轮 UI 升级增加可选目标 `Seis3DWorkspaceRegression`（`SEIS3D_BUILD_WORKSPACE_CHECKS=ON`），使用不可见 OpenGL 窗口运行真实 CUDA/GL 管线，已通过：

- 非整 warp 尺寸 33×31×29 的材质最小/最大值、Vp/Vs/密度切换与双通道数据检查。
- 真实 GLSL 编译、分层模型颜色差异、零波场叠加、纯波场模式和红绿调色板像素读回检查。
- 三种 DockSpace 预设、实际字号绘制与小网格 128 步模拟；64 个样本按每两步采集，资源冷释放检查。
- 四视图与体视图优先布局的离屏图像检查。
- 八种首页主题、首页双入口鼠标路由、浅色主题的旧画布对比适配，以及三维工作区的深浅色绘制检查。
- 默认 100 道、每道 64 个三分量样本的采集；110 点网格与 101 点 CUDA API 输入均被拒绝，并保留有效接收系统。
- 实际 ImGui 图像命令和窗口像素读回，确认切片纹理确实显示在界面中；鼠标滚轮锚点缩放、中键平移和 R 重置。
- 普通 Run 的真实接收点信号、完成后 Replay、512 帧环形缓存回卷与时间顺序，以及实时监视不覆盖正式道集。
- 四套显示预设、显示资源冷释放；无 OpenGL 错误。

2026-10-12 的显示修复对 Debug 与 RelWithDebInfo 主程序完整重建，并分别运行真实程序的 `--check-seis3d-display`：96³ 双层模型、三个不透明切片、100 道正式采集、完整尺寸界面均通过；生成的窗口图像已检查，可见模型分层、波前、体视图和三分量曲线。`Seis3DWorkspaceRegression` 在 Debug 下通过上述交互与集成检查。**以上是显示和集成检查，未完成三维物理精度回归、CUDA 内存检查、大型网格性能测量或所有手动拖拽交互的验收。**

因此不能把本实现视为已经通过勘探级精度认证的求解器。用于定量结论之前，应完成均匀介质 P/S 到时、空间/时间收敛、自由表面 Rayleigh 波、斜入射与角点 CPML 反射、液固接口能量、长期稳定性以及第三方 SEG-Y 读取兼容性验证。尤其应检查平面自由表面二阶闭合与侧向 CPML 交汇处的误差。
