# SeisWave Lab：论文准备与可复现实验路线

更新：2026-10-14。作者计划公开源码与合成实验数据，无期刊分区或费用硬性要求。本文件是准备计划；尚未投稿、发布仓库、生成 DOI，也没有把待做实验写成已有结果。

## 1. 论文定位

建议首先准备**科研软件论文**：面向消费级 NVIDIA GPU，将二维/三维弹性波求解、模型交互、实时显示和地震记录分析整合为可检查、可复用的研究工作流。可以考虑英文题目：

> SeisWave Lab: An interactive GPU-accelerated sandbox for elastic-wave simulation and seismic data analysis

已有八阶交错网格、CUDA、CPML 和图形界面的组合本身不足以证明新的数值方法。论文应量化：哪些科研操作得到改善、内存预算有什么收益、研究者如何复现实验，以及与现有工具相比能解决什么实际问题。方法论文则需要另外建立数值方法、并行算法或地球物理结果的创新证据。

可论证的贡献候选如下，均需数据支持后再写入摘要：

1. 有显存预算约束的二维/三维交互正演与冷切换架构。
2. 模型—震源—接收—采集—分析的统一操作流程及独立显示状态。
3. 可核查的原始记录、冻结模型、源子波和参数归档。
4. 对教学或研究调试的具体帮助，例如更短的配置时间、更容易识别边界反射或接收布局错误。

## 3. 必须明确的数据语义

### 3.1 震源与振幅

二维源类型 0/1/4 分别向速度注入垂向、水平和旋转体力，类型 2/3 为各向同性和剪切应力注入。遗留求解器使用 **1e7 数值注入尺度**；本轮将其统一为常量并写入清单，未改变其数值。

界面 Amplitude 是数值乘子，不能直接标成 N、N·m 或震级。做绝对振幅比较前，必须推导并核对 dt、网格体积/二维线源约定、密度、速度—应力时间交错和源积分；不同源机制不能用同一个界面数值宣称相同物理能量。

归档记录实际生效的源频率/延迟和实际落点，避免把尚未应用的界面草稿当作已计算参数。定量实验宜关闭鼠标追加多源。

### 3.2 时间和空间

- 记录 dt 是 stride×solver dt；SEG-Y 整数微秒值可能包含舍入，清单同时保留实际浮点值。
- 中途采集的 t=0 是局部采集起点；清单保留起始步，SEG-Y 延迟头当前为零。明确采样位于哪次速度更新之后，严格走时比较时核对半时间步偏移。
- 二维 SEG-Y Y 字段沿用垂向 Z；几何 CSV 提供 X/Z 真值。不能将其误作三维水平 Y。
- 原始记录与显示处理分离；AGC、归一化、波场增益与体渲染透明度不能用于物理振幅误差评价。
- CPU/GPU、不同平台及快速数学设置可能产生舍入差异，论文应使用有依据的容差，而非要求所有 GPU 位级一致。

## 4. 科学验证实验矩阵

每个实验固定模型、参数、代码版本和结果文件；提前定义误差与时间窗，保存原始数据，避免看完结果再选择有利指标。

| 编号 | 实验 | 主要指标与注意事项 |
| --- | --- | --- |
| V1 | 均匀全空间 P/S 波，远离边界的多位置三分量记录 | 波速/走时、相位、相对 L2 误差；优先解析解或制造解，匹配源机制、坐标和单位 |
| V2 | 空间与时间收敛，分别改变 h 与 dt | 误差随网格曲线及观察阶；减小 dt 隔离空间误差，反之亦然；点源与界面可能限制收敛 |
| V3 | 平面自由面、P/S 反射与 Rayleigh 波 | 牵引力残差、转换波振幅/走时和面波速度；检查与网格细化的关系 |
| V4 | 六面吸收，法向、斜入射、掠入射，不同主频与层厚 | 与扩大域参考比较的晚期误差和反射能量；明确窗口、距离和入射条件 |
| V5 | 分层、断层、球状异常等真实三维异质合成算例 | 三正交切面、三分量记录、独立参考一致性；使用有 Y 向变化的模型证明三维特性 |
| V6 | 对研究者有用的完整应用 | 从模型设置到原始炮集与后处理，报告研究问题、结果解释和可复现步骤 |

八阶内部差分不等于全局八阶精度；二阶时间格式、自由表面离散、材料不连续与源离散都会影响最终结果。流固界面如作为论文功能主张，应单独验证，未验证时限定适用范围。

现有二维 PML 晚到时间窗误差比约 0.04338，只是已有算例中的相对范数，**不能写成普适的 4.3% 边界反射系数**。已有结果和限制见 [二维审查](../development/SEIS2D_REFACTOR_AND_VIEWER.md) 与 [三维边界审查](../reviews/SEIS3D_VOLUME_BOUNDARY_REVIEW.md)。

### 独立参考候选

- [OpenSWPC](https://github.com/OpenSWPC/OpenSWPC)：二维/三维弹性与黏弹性正演；比较前核对其[垂向输出符号约定](https://openswpc.github.io/latest/2._Parameters/0205_output/)。
- [SW4](https://github.com/geodynamics/sw4)：三维弹性波工具，空间离散及吸收方式与当前项目不同；适合作物理结果参考，需要解释方法差异。
- [Devito 弹性交错网格示例](https://www.devitoproject.org/examples/seismic/tutorials/06_elastic_varying_parameters.html)：适合构建可读的独立方程/记录对照。

以上仅为参考实现选择建议，本轮未安装、运行或声称已完成跨软件对比。

## 5. 性能实验

建议覆盖 128³、160³、256³、300×300×400，以及具有不同长宽比的网格。大模型先做显存预检，不要求每台设备都运行全部规模。

1. 将初始化/模型上传、纯时间推进、接收采样、显示提取、体绘制和文件 I/O 分开统计。
2. CUDA 计算使用正确流上的事件并同步结束事件；CPU 墙钟统计完整操作的等待时间。报告计时方式、预热步骤、步数、重复次数、样本中位数和离散程度。
3. 报告 GPU/驱动/CUDA/编译器、精度、快速数学开关、网格、PML 厚度、线程块、显存占用与采样频率。
4. 报告 MLUPS（每秒百万格点更新）和模拟时长/墙钟时长。实时渲染 FPS 单列，不能直接称为正演加速比。
5. CPU 基准应采用相同物理问题和数值精度，披露线程数和优化；跨软件使用不同格式或边界时不宣称完全公平的原始速度排名。
6. 给出开启/关闭实时显示、采集、体视图时的开销，以及网格规模—显存—吞吐曲线。

当前没有新增伪造的跑分表。统一基准运行器及统计数据仍待实现。

## 8. 建议论文结构与图表

1. Introduction：研究需求、已有软件及当前缺口，说明工具适合什么用户。
2. Numerical formulation：控制方程、网格、时间交错、材料平均、源、边界、CFL、精度范围。
3. Software architecture：2D/3D 隔离、生命周期、GPU/GL 数据流、失败处理与内存预算。
4. Verification：V1–V4 的定量误差、收敛和独立对照。
5. Performance：计时方法、显存与吞吐、显示/采集开销、公平性限制。
6. Application and workflow：V5–V6，操作步骤与原始数据产出。
7. Availability and limitations：构建环境、许可证、版本、代码/数据 DOI、已知边界与未来工作。

建议图表内容：架构图、真实三维模型/切面、解析与模拟波形对照、网格收敛图、CPML 条件矩阵、GPU 性能/显存曲线，以及一张完整操作流程图。最终数量依目标期刊确定。科学曲线由原始数据独立绘图，带单位、坐标、色标及固定尺度；软件截图说明交互，不替代定量结果。
